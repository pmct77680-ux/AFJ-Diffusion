# Catalogue AFJ Diffusion - Exemple simple

Ce dépôt contient un site statique de démonstration prêt à être publié via GitHub Pages.

Instructions rapides:
1. Créez un dépôt sur GitHub et copiez les fichiers fournis.
2. Vérifiez que le fichier index.html et le dossier css/styles.css sont présents.
3. Poussez sur la branche main.
4. Dans les paramètres du dépôt, activez GitHub Pages (Source: branch main, dossier root).
5. Le site sera disponible quelques minutes plus tard à l'URL fournie par GitHub.

Pour remplacer le contenu par votre catalogue:
1. Ouvrez votre fichier HTML local.
2. Copiez les balises <article class="product-card">...</article> de l'exemple et collez vos produits en conservant la structure, ou remplacez tout le <main> si vous avez un layout complet.
3. Si vous avez des images locales, mettez-les dans un dossier assets/images et remplacez les src des <img> par "assets/images/nom.jpg".
