# AFJ Diffusion - Base pour site statique

Dépôt minimal prêt pour GitHub Pages.

Installation rapide:
1. Placez ce dépôt sur GitHub.
2. Ajoutez vos images dans `assets/images/` (créez le dossier si nécessaire).
3. Vérifiez que `index.html` et `css/styles.css` existent.
4. Poussez sur la branche `main`.
5. **Activez GitHub Pages**: Settings > Pages, Source: branch `main`, folder `/ (root)`.

Personnalisation:
- Dupliquez les balises `<article class="product-card">` pour ajouter des produits.
- Modifiez les couleurs dans `css/styles.css` (variables :root).
